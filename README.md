### 👋 About

I'm a full-stack engineer and founder of **[Vevlet](#)** — *"Where Code Meets Elegance"* — a boutique studio in Peshawar building custom platforms for real estate, education, and luxury/hospitality brands across Pakistan, the UK, and the UAE.

Currently a 7th-semester Computer Science student at IM Sciences, interning at **ESEF** (a Government of Khyber Pakhtunkhwa education body), and running client work on the side. Also a musician and photographer — which is where the obsession with clean, deliberate UI comes from.
